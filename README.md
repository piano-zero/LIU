## 📖 Cos'è LIU'?

**LIU' (Letture In Uscita)** è un software gestionale open-source progettato per semplificare la quotidianità del bibliotecario.

L'obiettivo è rimuovere le barriere tecnologiche: niente server complicati o configurazioni cloud. LIU' permette di tracciare chi ha preso cosa e quando deve restituirlo, offrendo una visione chiara e immediata dello stato della biblioteca, ottimizzando il lavoro degli operatori e riducendo gli errori.

## ✨ Funzionalità Principali

* 👥 **Anagrafica Lettori:** Gestione completa dei profili utenti, con storico dei prestiti e contatti rapidi.
* 🔄 **Gestione Prestiti:** Sistema di Check-in e Check-out immediato. Associa un libro a un lettore in pochi secondi.
* scadenze **Monitoraggio Scadenze:** Visualizzazione chiara dei libri in ritardo o in scadenza, per facilitare i solleciti.
* 📊 **Storico Movimenti:** Tieni traccia di tutti i movimenti passati per statistiche e controllo.
* 🔍 **Ricerca Rapida:** Motore di ricerca interno per trovare istantaneamente libri o utenti nel database.

## 🔒 Sicurezza e Dati

**La privacy e il controllo dei dati sono al primo posto.**

* **Archiviazione Locale:** LIU' non invia dati al cloud. Tutto viene salvato in un database locale (`.db`) sul tuo computer.
* **Responsabilità:** L'utente è l'unico proprietario e responsabile della salvaguardia del database.
* **Backup:** Si consiglia vivamente di effettuare copie di backup periodiche della cartella del programma o del file database su supporti esterni.

## 🚀 Installazione

### Prerequisiti
* Python 3.x installato sul sistema.

### Avvio Rapido

1.  **Clona il repository:**
    ```bash
    git clone [https://github.com/piano-zero/LIU_Gestionale.git](https://github.com/piano-zero/LIU.git)
    ```

2.  **Installa le dipendenze (se presenti):**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Avvia il programma:**
    ```bash
    python liu_main.py
    ```
